# 📝 TODO LIST

This Android application is being developed as part of a personal project to enhance and update my knowledge of Android development. The goal is to create a simple, efficient, and scalable application using industry best practices and modern tools from the Android ecosystem.

## 🚀 Technologies and Tools Used

- **Kotlin**: The official language for Android development.
- **Jetpack Compose**: The modern toolkit for building native user interfaces.
- **Room Database**: For local database management.
- **Coroutines**: Efficient handling of asynchronous operations.
- **Hilt**: Simplified and powerful dependency injection.
- **MVVM (Model-View-ViewModel)**: Architecture that separates concerns and facilitates state management.

This project is an opportunity to explore the latest innovations in Android development, with a focus on building a solid foundation for modern and scalable applications.
